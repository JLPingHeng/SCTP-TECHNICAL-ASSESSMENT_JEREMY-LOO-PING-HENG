**(c)** The SCTP course assumes a POSIX shell (bash or zsh). In your course material, you may encounter commands like these:

```bash
touch notes.txt
export API_KEY=abc123
chmod +x setup.sh
source venv/bin/activate
```

Give **one concrete reason** why running commands like these on Windows PowerShell can fail, even though some commands look similar to PowerShell at first glance. A general-knowledge answer is fine; you do not need to have used PowerShell yourself.

**Answer:**
_Windows PowerShell fails on POSIX commands like export because it uses its own distinct command language and system architecture; POSIX commands are designed for Unix-based systems (Linux/macOS) and are not natively recognized by PowerShell. The command "export" works in Bash/Zsh and does not exist in PowerShell (The command "$env:" should be used in PowerShell)._
